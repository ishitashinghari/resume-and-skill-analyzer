# 📄 Resume Analyzer

An AI-powered Resume Analyzer that compares a candidate's resume with a job description and provides:

- 📊 Resume Match Score
- 🧠 Semantic Similarity Score
- 🔑 Keyword Matching Analysis
- ❌ Missing Skills Detection
- ✅ Matched Skills
- 🤖 AI-generated Strengths, Weaknesses & Suggestions using Groq LLM

---

## 🚀 Features

- Upload resume in **PDF** format
- Paste any Job Description
- Extracts resume text automatically
- Intelligent keyword extraction using **spaCy + KeyBERT**
- Semantic similarity using **Sentence Transformers**
- Lemmatization-based keyword matching
- AI-powered resume feedback using **Groq API**
- Clean and responsive UI built with HTML & CSS

# ⚙️ How It Works

## 1. Resume Upload

The user uploads a resume in PDF format and pastes a Job Description.

---

## 2. Text Extraction

The uploaded PDF is read using **PyPDF2**, and all pages are converted into plain text.

---

## 3. Text Cleaning

The extracted text is cleaned by:

- Removing unnecessary whitespace
- Repairing broken PDF spacing
- Normalizing the text

---

## 4. Candidate Phrase Extraction (spaCy)

spaCy analyzes the document and extracts meaningful noun phrases.

Example:

Resume:

```
Developed a Resume Analyzer using Flask and Machine Learning.
```

spaCy extracts:

```
Resume Analyzer
Machine Learning
Flask
```

instead of noisy phrases like:

```
using Flask
Developed Resume
```

Technical words like **RAG**, **CNN**, **GitHub**, **Flask**, etc., are also preserved.

---

## 5. Keyword Ranking (KeyBERT)

The candidate phrases generated by spaCy are passed to KeyBERT.

KeyBERT:

- Creates embeddings for the document
- Creates embeddings for each candidate phrase
- Computes cosine similarity
- Ranks the most representative keywords
- Uses MMR (Maximal Marginal Relevance) to reduce repetitive keywords

Example output:

```
Machine Learning
Python
Flask
Resume Analyzer
Git
```

---

## 6. Lemmatization

Both the Resume and Job Description are lemmatized using spaCy.

Example:

```
Developing
Developed
Develops
```

↓

```
develop
```

This improves keyword matching by reducing words to their base forms.

---

## 7. Keyword Matching

Every keyword extracted from the Job Description is checked against the lemmatized Resume.

Output:

### ✅ Matched Keywords

```
Python
Machine Learning
Flask
```

### ❌ Missing Keywords

```
Docker
Kubernetes
TensorFlow
```

---

## 8. Semantic Similarity

Sentence Transformers convert the Resume and Job Description into dense vector embeddings.

Cosine Similarity is computed between both embeddings.

The semantic similarity contributes **50%** of the final score.

---

## 9. Final Match Score

Final Score =

```
Semantic Score (50)
+
Keyword Score (50)
=
100
```

---

## 10. AI Feedback

Groq LLM receives:

- Resume
- Job Description
- Matched Keywords
- Missing Keywords

It returns structured JSON containing:

- Strengths
- Weaknesses
- Suggestions

This gives users actionable feedback to improve their resume.

# 📦 Installation
 
Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create a `.env` file in the root directory.

```
GROQ_API_KEY=your_api_key
```
